# PureBrain Video Editor - Community Edition

Professional multi-track video editing built with React, TypeScript, and Remotion.

## Features

- Multi-track timeline with drag-and-drop
- Text overlays, transitions, and effects
- Audio track support
- Export to multiple formats
- AI-powered editing assistance

## Tech Stack

- **Frontend:** React, TypeScript, Next.js
- **Video Engine:** Remotion / DesignCombo
- **Styling:** Tailwind CSS

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev
```
